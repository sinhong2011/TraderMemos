[起動が完了した](/ja/docs/getting-started/quick-start)ら、空のインスタンスから「何かを教えて
くれるジャーナル」までの道のりを見ていきましょう。

## 1. セットアップウィザード

初回アクセス時、TraderMemos はデータベースが空であることを検出し、一度だけセットアップ画面を
表示します。

1. **オーナーアカウント** — ログイン名とパスワード（10 文字以上）。これが管理者になります。
   以降、`TM_ALLOW_REGISTRATION` を有効にしない限り、一般登録は閉じたままです。
2. **トレード口座** — 名前（既定は *Main*）、通貨、初期残高。この残高は資金台帳の
   *開始残高*入金として記録されます。
3. **任意のインポート** — CSV または TraderMemos の JSON バックアップを投入してジャーナルに
   初期データを入れられます。スキップして空の状態から始めても構いません。インポートは後から
   いつでも可能です。

新規ユーザーには、よく使われる 9 つのプレイブックセットアップ（Pullback、Breakout、Reversal
など）があらかじめ用意されています。**プレイブック**で名前を変更したり、入れ替えたりできます。

## 2. トレードを取り込む

方法は 3 つあり、自由に組み合わせられます。

- **証券会社の CSV をインポート** — ジャーナルを最短で埋める方法です。
  [トレードのインポート](/ja/docs/guides/importing-trades)を参照してください。
- **新規トレード**（ホットキー `c` `t`）— 約定行、セットアップ、タグ、感情、スクリーンショット、
  メモを手入力します。[AI 機能](/ja/docs/guides/ai-features)を有効にすると、
  **スキャンして入力**で証券会社のスクリーンショットから約定を抽出できます。
- **自動化する** — [tm-sync](https://github.com/sinhong2011/TraderMemos/blob/main/docs/tm-sync.md)
  デスクトップウォッチャーは MT4/MT5 の明細を出力と同時にインポートし、IBKR 口座は
  Flex Query によるスケジュール自動同期（**設定 → 口座 → Flex 同期**）が使えます。
- **まずは試してみたい場合** — リアルなデモトレードを約 200 件投入します。
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

約定は自動的にトレード単位へグループ化され（買い増し・分割決済も含みます）、重複は常に
スキップされるため、二重計上が起きることはありません。

## 3. 画面をひととおり把握する

| ページ | ホットキー | 用途 |
|------|--------|---------------|
| **ホーム** | `G` `H` | 資産曲線、損益ヒーロー、連勝・連敗、期待値、目標進捗 |
| **トレード** | `G` `T` | トレードログ — フィルタ、並べ替え、約定やジャーナル詳細へのドリルダウン |
| **カレンダー** | `G` `C` | 日次の損益ヒートマップ。週間合計とドリルダウン付き |
| **レポート** | `G` `S` | 期待値、SQN、ケリー%、モンテカルロ、執行クオリティ。セットアップ別／時間帯別／セッション別の内訳 |
| **ノート** | `G` `N` | 自由形式のメモと日次ログ |
| **プレイブック** | `G` `P` | 自分のセットアップと、それを使ったトレードへのリンク |
| **計算機** | `G` `R` | ポジションサイズ／R 計算機 |
| **インポート** | `G` `I` | インポートとエクスポート |
| **設定** | `⌘` `,` | 口座、ルールとアラート、ジャーナル、AI、API トークン、共有、ユーザー |

`⌘K` でどこからでもコマンドパレットを開けます。残りの画面 — 高機能チャート、バーリプレイ、
経済指標カレンダー、FX・ケリー計算機、Year Wrapped — は**ツール**メニューにあります。
すべてのキー割り当ては**設定 → ショートカット**で変更できます。

## 4. レビューの習慣をつくる

ジャーナルの価値は記録そのものではなく、振り返りのサイクルにあります。

1. **すべてのトレードにタグを付ける** — プレイブックのセットアップを必ず割り当て、必要に応じて
   ミスや感情も記録します。タグのないトレードは何も教えてくれません。
2. **毎週レポートを確認する** — セットアップ別の内訳が、実際に利益を生んでいるパターンを示して
   くれます。プレイブックは期待値とプロフィットファクターで各セットアップをランク付けします。
3. **ガードレールを設定する** — **設定 → ルール**にリスク上限（1 トレードあたりの最大リスク、
   1 日の最大損失）を設定でき、新規トレード時のコンプライアンスチェックで適用されます。年間目標
   を設定すればダッシュボードが進捗ペースを表示します。
4. **サイズを一貫させる** — ポジションサイズ計算機（`⌘⇧P`）が、口座資産と既定のリスク率から
   数量を算出します。

## 5. 本格的に使い始める前に

実データを扱う前に、2 分だけ運用面の準備をしておきましょう。

- 本番向けの堅牢化 — JWT シークレットと TLS: [デプロイ](/ja/docs/self-hosting/deploy)
- 自動バックアップ: [バックアップと復元](/ja/docs/self-hosting/backup-restore)
