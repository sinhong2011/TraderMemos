[起動が完了した](/ja/docs/getting-started/quick-start)ら、空のインスタンスから「何かを教えて
くれるジャーナル」までの道のりを見ていきましょう。

## 1. セットアップウィザード

初回アクセス時、TraderMemos はデータベースが空であることを検出し、一度だけセットアップ画面を
表示します。

1. **オーナーアカウント** — ログイン名とパスワード（10 文字以上）。これが管理者になります。
   以降、`TM_ALLOW_REGISTRATION` を有効にしない限り、一般登録は閉じたままです。
2. **トレード口座** — 名前（既定は *Main*）、通貨、初期残高。この残高は資金台帳の
   *開始残高*入金として記録されます。
3. **任意のインポート** — CSV または TraderMemos の JSON バックアップを投入してジャーナルに
   初期データを入れられます。スキップして空の状態から始めても構いません。インポートは後から
   いつでも可能です。

新規ユーザーには、よく使われる 9 つのプレイブックセットアップ（Pullback、Breakout、Reversal
など）があらかじめ用意されています。**プレイブック**で名前を変更したり、入れ替えたりできます。

## 2. トレードを取り込む

方法は 3 つあり、自由に組み合わせられます。

- **証券会社を接続** — `/connect`（インポートページの **Find my broker**、またはアカウントページの
  **Connect broker**）を開くと、
  検索できる証券会社カタログが **Auto-sync / File import / Manual** に分かれて表示されます。
  証券会社を選び、その場でアカウントを選択または作成したら、その証券会社のエクスポート手順に
  従います。Interactive Brokers なら Flex Query を入力すると、最初の同期がすぐに実行されます。
- **証券会社の CSV をインポート** — ジャーナルを最短で埋める方法です。
  [トレードのインポート](/ja/docs/guides/importing-trades)を参照してください。
- **新規トレード**（ホットキー `c` `t`）— 約定行、セットアップ、タグ、感情、スクリーンショット、
  メモを手入力します。[AI 機能](/ja/docs/guides/ai-features)を有効にすると、
  **スキャンして入力**で証券会社のスクリーンショットから約定を抽出できます。
- **自動化する** — IBKR 口座は Flex Query によるスケジュール自動同期が使えます。`/connect`
  か、アカウントページの **Interactive Brokers · Flex sync** カードから設定します。
- **まずは試してみたい場合** — リアルなデモトレードを約 200 件投入します。
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

約定は自動的にトレード単位へグループ化され（買い増し・分割決済も含みます）、重複は常に
スキップされるため、二重計上が起きることはありません。

## 3. 画面をひととおり把握する

| ページ | ホットキー | 用途 |
|------|--------|---------------|
| **ホーム** | `G` `H` | 資産曲線、損益ヒーロー、連勝・連敗、期待値、目標進捗 |
| **今日** | `G` `D` | 取引日を 1 ページに — ルーティン、デスク（日次損失ガードレール、オープンリスク）、セッション損益、見送ったトレード、日次ログ |
| **トレード** | `G` `T` | トレードログ — フィルタ、並べ替え、約定やジャーナル詳細へのドリルダウン |
| **カレンダー** | `G` `C` | 日次の損益ヒートマップ。週間合計とドリルダウン付き |
| **レポート** | `G` `S` | 期待値、SQN、ケリー%、モンテカルロ、執行クオリティ。セットアップ別／時間帯別／セッション別の内訳 |
| **ノート** | `G` `N` | 自由形式のメモと日次ログ |
| **プレイブック** | `G` `P` | 自分のセットアップと、それを使ったトレードへのリンク |
| **計算機** | `G` `R` | R-multiple & FVG のトレードプランナー |
| **インポート** | `G` `I` | インポートとエクスポート |
| **設定** | `⌘` `,` | プロフィール（パスワード、二要素認証）、一般（言語、タイムゾーン、テーマ）、ショートカット、アカウント、ルールとアラート、ジャーナル、AI、API トークン、共有、ユーザー、について（バージョン、バックアップ） |

`⌘K` でどこからでもコマンドパレットを開けます。ホットキーのない画面もここから開けます —
**ルーティン**と**見送ったトレード**（どちらも今日のページからも開けます）、そして
**振り返り**インボックス（`/review`）です。残りの画面 — ポジションサイズ、ケリー、通貨換算、
R-multiple & FVG、高機能チャート、リプレイ、経済指標カレンダー、Year Wrapped — は**ツール**
メニューにあります。
すべてのキー割り当ては**設定 → ショートカット**で変更できます。

## 4. レビューの習慣をつくる

ジャーナルの価値は記録そのものではなく、振り返りのサイクルにあります。

1. **毎セッションを今日のページから始める**（`G` `D`）— ルーティンにチェックを入れ、日次損失
   ガードレールを確認し、見送ったトレードを記録します。
   [デイリーワークフロー](/ja/docs/guides/daily-workflow)を参照してください。
2. **振り返りインボックスを空にする** — 直近 14 日間に決済され、執行グレードが付いていない
   トレードが**振り返り**（`/review`、今日のページからリンク）に 1 件ずつ並びます。ついでに
   セットアップ、ミス、感情のタグも付けましょう。タグのないトレードは何も教えてくれません。
3. **週次レビューを書く** — 毎週土曜、サーバーがその週の数字を入れたレビューノートを下書き
   します。*Focus for next week* の下に書いた箇条書きが、今日のページとモバイルのホームの
   **今週のフォーカス**になり、レポート → 行動 でどれだけ守れたかを追跡できます。
   [週次レビュー](/ja/docs/guides/weekly-review)を参照してください。
4. **セットアップの評価は数字に任せる** — プレイブックはセットアップを判定（Edge、Promising、
   Watch、Too early、Execution leak、Bleeding）と期待値の信頼区間で並べるため、たまたま
   勝った 4 トレードがエッジに見えることはありません。レポートにはミス税と Edge Score も
   あります — [分析](/ja/docs/guides/analytics)を参照してください。
5. **ガードレールを設定する** — **設定 → ルール**にリスク上限（1 トレードあたりの最大リスク、
   1 日の最大損失）を設定すると新規トレード時のコンプライアンスチェックで適用され、年間目標は
   ダッシュボードが進捗ペースを表示し、アラートが警告します
   （[アラートと共有](/ja/docs/guides/alerts-and-sharing)）。ポジションサイズ計算機
   （`⌘⇧P`）は口座資産と既定のリスク率から数量を算出します。

## 5. 本格的に使い始める前に

実データを扱う前に、2 分だけ運用面の準備をしておきましょう。

- 本番向けの堅牢化 — JWT シークレットと TLS: [デプロイ](/ja/docs/self-hosting/deploy)
- 自動バックアップ: [バックアップと復元](/ja/docs/self-hosting/backup-restore)
