Web アプリと同じアカウント・トレード・レポートを、外出先でもオフラインで参照できます。
1 つの Expo コードベースが両プラットフォームをカバーします。

## iOS

ベータ期間中、iOS ビルドは **TestFlight** で配信されます。ウィジェット、Live
Activities、Siri / アクションボタンでのクイック記録は iOS 専用の機能です。

## Android

Play ストアでの配信はありません — GitHub リリースページの APK が Android の配信
チャネルです:

1. **[TraderMemos.apk をダウンロード](https://github.com/sinhong2011/TraderMemos/releases/latest/download/TraderMemos.apk)** — このリンクは常に最新リリースを
   指します。特定のビルドが必要な場合は[リリース一覧](https://github.com/sinhong2011/TraderMemos/releases/latest)から選んでください。
2. スマートフォンでファイルを開き、Android の確認が出たらブラウザまたはファイル
   マネージャーに対して**不明なアプリのインストール**を許可します。Chrome は APK の
   ダウンロード時に必ず警告を出しますが、これはサイドロード全般に対する警告であり、
   このファイル固有のものではありません。
3. アップデートは、新しいリリースの APK を上書きインストールするだけです —
   その場で更新され、データは保持されます。

ダウンロードを検証したい場合のために、各リリースには `TraderMemos.apk.sha256` が
同梱されています。保存用にバージョン付きの `TraderMemos-<version>.apk` も併せて
配布しています。

## サーバーへの接続

初回起動時に、インスタンスの URL（例: `https://journal.example.com` や
`http://192.168.1.10:8080`）と認証情報を入力します — Web アプリと同じ
「ログイン時にサーバーを指定する」方式です。アプリはまず `/healthz` を確認する
ため、サーバーに到達できない場合は認証エラーではなく接続エラーとして報告されます。

スマートフォンからサーバーに到達できる必要があります: 同一 LAN 内、VPN /
トンネル経由、または公開 HTTPS ドメイン経由です
（[リバースプロキシ](/ja/docs/self-hosting/reverse-proxy)を参照）。トークンは
プラットフォームのキーストア（iOS Keychain / Android Keystore）に保存され、
平文では保存されません。
