TraderMemos のコンパニオンアプリは、**自分のサーバー**に対して記帳します —
Web アプリと同じアカウント・トレード・レポートを外出先でも扱え、オフラインでも動きます。
読み込みはローカルキャッシュから行われ、記帳（メモやクイックジャーナルの編集）はキューに入り、
サーバーに再接続すると順番に反映されます。
1 つの Expo コードベースが両プラットフォームをカバーします。

## iOS

**[App Store で TraderMemos をダウンロード](https://apps.apple.com/app/id6797427206)**。iOS 専用の機能:

- **ウィジェット** — Today、**Daily Routine**（ホーム画面とロック画面。項目をタップすると
  アプリを開かずにチェック）、**Missed Trades**。
- **コントロールセンター**（iOS 18 以降）— *Next Routine Item* で次の未完了項目にチェック、
  *Log Missed Trade* でフォームを開きます。
- **Siri・ショートカット・Spotlight** — Journal Last Trade、Log a Trade、Check Off Routine
  Item、Next Routine Item、Routine Progress、Log Missed Trade。
- 取引セッション中の **Live Activities**。

## Android

Play ストアでの配信はありません — GitHub リリースページの APK が Android の配信
チャネルです:

1. **[TraderMemos.apk をダウンロード](https://github.com/sinhong2011/TraderMemos/releases/latest/download/TraderMemos.apk)** — このリンクは常に最新リリースを
   指します。特定のビルドが必要な場合は[リリース一覧](https://github.com/sinhong2011/TraderMemos/releases/latest)から選んでください。
2. スマートフォンでファイルを開き、Android の確認が出たらブラウザまたはファイル
   マネージャーに対して**不明なアプリのインストール**を許可します。Chrome は APK の
   ダウンロード時に必ず警告を出しますが、これはサイドロード全般に対する警告であり、
   このファイル固有のものではありません。
3. アップデートは、新しいリリースの APK を上書きインストールするだけです —
   その場で更新され、データは保持されます。

ダウンロードを検証したい場合のために、各リリースには `TraderMemos.apk.sha256` が
同梱されています。保存用にバージョン付きの `TraderMemos-<version>.apk` も併せて
配布しています。

## サーバーへの接続

初回起動時に、**サーバーアドレス**へインスタンスの URL（例: `https://journal.example.com` や
`http://192.168.1.10:8080`）を、続けて認証情報を入力します — Web アプリと同じ「ログイン時に
サーバーを指定する」方式です。アプリはまず `/healthz` を確認するため、サーバーに到達できない
場合は認証エラーではなく接続エラーとして報告されます。サーバーにまだユーザーがいない場合は、
Web のセットアップウィザードと同じ初期設定画面（**オーナーアカウントを作成**）が表示されます。
あとから別のサーバーに切り替えるには、設定の**サーバーを変更**を使います。

スマートフォンからサーバーに到達できる必要があります: 同一 LAN 内、VPN /
トンネル経由、または公開 HTTPS ドメイン経由です
（[リバースプロキシ](/ja/docs/self-hosting/reverse-proxy)を参照）。トークンは
プラットフォームのキーストア（iOS Keychain / Android Keystore）に保存され、
平文では保存されません。

## 日々の使い方

ホームの先頭には振り返りのサイクルが並びます。**今週のフォーカス**（前回の週次レビューの箇条書き）、
今日のルーティン、そして振り返りキューを開く「N 件のトレードを振り返る」行です。キューでは
1 件ずつグレードを付け、**保存して次へ**か**今はスキップ**を選びます。
[デイリーワークフロー](/ja/docs/guides/daily-workflow)と
[週次レビュー](/ja/docs/guides/weekly-review)を参照してください。
