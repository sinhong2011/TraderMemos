已經[跑起來了](/zh-Hant/docs/getting-started/quick-start)？下面是從空實例到一份真正有
洞察的交易日誌的路徑。

## 1. 初始化嚮導

首次訪問時，TraderMemos 檢測到空數據庫會顯示一次性初始化流程：

1. **Owner 賬戶** —— 登錄名與密碼（至少 10 位）。這是管理員賬戶；此後公開註冊保持關閉，
   除非開啓 `TM_ALLOW_REGISTRATION`。
2. **交易賬戶** —— 名稱（默認 *Main*）、貨幣與初始資金。初始資金會成爲現金流水中的一筆
   *期初餘額* 存入記錄。
3. **可選導入** —— 拖入 CSV 或 TraderMemos 的 JSON 備份爲日誌注入數據，也可以跳過從零開始。
   之後隨時都能導入。

每個新用戶會預置九個常見策略（回調、突破、反轉……）—— 可在**策略手冊**中重命名或替換。

## 2. 錄入交易

三種方式，可自由組合：

- **連接券商** —— `/connect`（導入頁面的 **Find my broker**，或賬戶頁面的 **Connect broker**）
  打開可搜尋的券商目錄，
  按 **Auto-sync / File import / Manual** 分組。選中你的券商，就地選擇或新建賬戶，然後按該
  券商的導出步驟操作；Interactive Brokers 則填入 Flex Query，首次同步會立即執行。
- **導入券商 CSV** —— 最快填滿日誌的方式。參見[導入交易](/zh-Hant/docs/guides/importing-trades)。
- **新建交易**（快捷鍵 `c` `t`）—— 手動錄入，含成交行、策略、標籤、情緒、截圖與筆記。開啓
  [AI 功能](/zh-Hant/docs/guides/ai-features)後，**掃描填充**可直接從券商截圖提取成交。
- **自動化** —— IBKR 賬戶可通過 Flex Query 定時自動同步，在 `/connect` 或賬戶頁面的
  **Interactive Brokers · Flex sync** 卡片中設置。
- **只是想先看看？** 填充約 200 筆逼真的演示交易：
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

成交會自動歸組爲交易（包括加倉與分批離場），重複記錄總是被跳過 —— 這裏不會出現重複計算。

## 3. 認識各個頁面

| 頁面 | 快捷鍵 | 用途 |
|------|--------|---------------|
| **首頁** | `G` `H` | 權益曲線、盈虧概覽、連勝連虧、期望值、目標進度 |
| **今日** | `G` `D` | 一頁看完整個交易日 —— 例行清單、交易台（單日虧損護欄、持倉風險）、當日盈虧、錯過的交易、每日日誌 |
| **交易** | `G` `T` | 交易記錄 —— 篩選、排序，下鑽查看成交與日誌詳情 |
| **日曆** | `G` `C` | 按日盈虧熱力圖，含每週合計與下鑽 |
| **報表** | `G` `S` | 期望值、SQN、凱利比例、蒙地卡羅、執行品質；按策略 / 小時 / 時段細分 |
| **筆記** | `G` `N` | 自由筆記與每日日誌 |
| **策略手冊** | `G` `P` | 你的策略庫，每個策略關聯使用它的交易 |
| **計算器** | `G` `R` | R-multiple & FVG 交易規劃器 |
| **導入** | `G` `I` | 導入與導出 |
| **設置** | `⌘` `,` | 個人檔案（密碼、雙重認證）、一般（語言、時區、主題）、快捷鍵、賬戶、規則與警報、日誌、AI、API 令牌、分享、用戶、關於（版本、備份） |

`⌘K` 隨時打開命令面板。沒有快捷鍵的頁面也在這裏：**例行清單**與**錯過的交易**（也可從今日頁面
打開），以及**覆盤**收件匣（`/review`）。其餘工具 —— 部位、凱利、貨幣換算、R-multiple & FVG、
進階圖表、回放、財經日曆、Year Wrapped —— 都在**工具**選單裏。所有快捷鍵均可在**設置 → 快捷鍵**中重新綁定。

## 4. 養成復盤習慣

日誌的價值在循環裏，不在記錄裏：

1. **每個交易日從今日頁面開始**（`G` `D`）—— 勾選例行清單、留意單日虧損護欄、把放棄的機會記成
   錯過的交易。參見[每日流程](/zh-Hant/docs/guides/daily-workflow)。
2. **清空覆盤收件匣** —— 最近 14 天內已平倉但還沒有執行評分的交易，會在**覆盤**（`/review`，
   今日頁面有入口）裏逐筆排隊。順手打上策略、錯誤類型與情緒標籤 —— 沒有標籤的交易教不了你任何東西。
3. **寫週復盤** —— 每週六伺服器會起草一篇附上本週數據的復盤筆記。你在 *Focus for next week*
   下寫的要點，會成為今日頁面與行動端首頁上的**本週重點**；報表 → 行為會追蹤你守住了多少。
   參見[週復盤](/zh-Hant/docs/guides/weekly-review)。
4. **讓數據評判策略** —— 策略手冊按判定（Edge、Promising、Watch、Too early、Execution leak、
   Bleeding）與期望值區間排序，四筆僥倖的盈利不會被當成優勢。報表還提供錯誤成本（mistake tax）
   與 Edge Score —— 參見[分析](/zh-Hant/docs/guides/analytics)。
5. **設好護欄** —— **設置 → 規則**中的風控上限（單筆最大風險、單日最大虧損）會被新建交易的
   合規檢查強制執行；年度目標由儀表盤跟蹤進度；警報會及時提醒你
   （[警報與分享](/zh-Hant/docs/guides/alerts-and-sharing)）。部位計算器（`⌘⇧P`）基於賬戶
   權益與默認風險比例計算。
