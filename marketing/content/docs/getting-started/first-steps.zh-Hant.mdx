已經[跑起來了](/zh-Hant/docs/getting-started/quick-start)？下面是從空實例到一份真正有
洞察的交易日誌的路徑。

## 1. 初始化嚮導

首次訪問時，TraderMemos 檢測到空數據庫會顯示一次性初始化流程：

1. **Owner 賬戶** —— 登錄名與密碼（至少 10 位）。這是管理員賬戶；此後公開註冊保持關閉，
   除非開啓 `TM_ALLOW_REGISTRATION`。
2. **交易賬戶** —— 名稱（默認 *Main*）、貨幣與初始資金。初始資金會成爲現金流水中的一筆
   *期初餘額* 存入記錄。
3. **可選導入** —— 拖入 CSV 或 TraderMemos 的 JSON 備份爲日誌注入數據，也可以跳過從零開始。
   之後隨時都能導入。

每個新用戶會預置九個常見策略（回調、突破、反轉……）—— 可在**策略手冊**中重命名或替換。

## 2. 錄入交易

三種方式，可自由組合：

- **導入券商 CSV** —— 最快填滿日誌的方式。參見[導入交易](/zh-Hant/docs/guides/importing-trades)。
- **新建交易**（快捷鍵 `c` `t`）—— 手動錄入，含成交行、策略、標籤、情緒、截圖與筆記。開啓
  [AI 功能](/zh-Hant/docs/guides/ai-features)後，**掃描填充**可直接從券商截圖提取成交。
- **自動化** —— [tm-sync](https://github.com/sinhong2011/TraderMemos/blob/main/docs/tm-sync.md)
  桌面監控會在 MT4/MT5 對賬單生成後立即導入；IBKR 賬戶可通過 Flex Query 定時自動同步
  （**設置 → 賬戶 → Flex 同步**）。
- **只是想先看看？** 填充約 200 筆逼真的演示交易：
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

成交會自動歸組爲交易（包括加倉與分批離場），重複記錄總是被跳過 —— 這裏不會出現重複計算。

## 3. 認識各個頁面

| 頁面 | 快捷鍵 | 用途 |
|------|--------|---------------|
| **首頁** | `G` `H` | 權益曲線、盈虧概覽、連勝連虧、期望值、目標進度 |
| **交易** | `G` `T` | 交易記錄 —— 篩選、排序，下鑽查看成交與日誌詳情 |
| **日曆** | `G` `C` | 按日盈虧熱力圖，含每週合計與下鑽 |
| **報表** | `G` `S` | 期望值、SQN、凱利比例、蒙地卡羅、執行品質；按策略 / 小時 / 時段細分 |
| **筆記** | `G` `N` | 自由筆記與每日日誌 |
| **策略手冊** | `G` `P` | 你的策略庫，每個策略關聯使用它的交易 |
| **計算器** | `G` `R` | 部位 / R 計算器 |
| **導入** | `G` `I` | 導入與導出 |
| **設置** | `⌘` `,` | 賬戶、規則與警報、日誌、AI、API 令牌、分享、用戶 |

`⌘K` 隨時打開命令面板。其餘頁面 —— 進階圖表、K 線回放、財經日曆、匯率與凱利計算器、
Year Wrapped —— 都在**工具**選單裏。所有快捷鍵均可在**設置 → 快捷鍵**中重新綁定。

## 4. 養成復盤習慣

日誌的價值在循環裏，不在記錄裏：

1. **每筆交易都打上策略標籤**（必要時加上錯誤類型與情緒）—— 沒有標籤的交易教不了你任何東西。
2. **每週看報表** —— 策略細分告訴你哪些模式真正賺錢；策略手冊按期望值與盈利因子排序。
3. **設好護欄** —— **設置 → 規則**中的風控上限（單筆最大風險、單日最大虧損）會被新建交易的
   合規檢查強制執行；年度目標則由儀表盤跟蹤進度。
4. **穩定的倉位管理** —— 倉位計算器（`⌘⇧P`）基於你的賬戶權益與默認風險比例計算。
