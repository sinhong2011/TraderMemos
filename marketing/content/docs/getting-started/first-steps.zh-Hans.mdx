已经[跑起来了](/zh-Hans/docs/getting-started/quick-start)？下面是从空实例到一份真正有
洞察的交易日志的路径。

## 1. 初始化向导

首次访问时，TraderMemos 检测到空数据库会显示一次性初始化流程：

1. **Owner 账户** —— 登录名与密码（至少 10 位）。这是管理员账户；此后公开注册保持关闭，
   除非开启 `TM_ALLOW_REGISTRATION`。
2. **交易账户** —— 名称（默认 *Main*）、货币与初始资金。初始资金会成为现金流水中的一笔
   *期初余额* 存入记录。
3. **可选导入** —— 拖入 CSV 或 TraderMemos 的 JSON 备份为日志注入数据，也可以跳过从零开始。
   之后随时都能导入。

每个新用户会预置九个常见策略（回调、突破、反转……）—— 可在**策略手册**中重命名或替换。

## 2. 录入交易

三种方式，可自由组合：

- **导入券商 CSV** —— 最快填满日志的方式。参见[导入交易](/zh-Hans/docs/guides/importing-trades)。
- **新建交易**（快捷键 `n`）—— 手动录入，含成交行、策略、标签、情绪、截图与笔记。开启
  [AI 功能](/zh-Hans/docs/guides/ai-features)后，**扫描填充**可直接从券商截图提取成交。
- **只是想先看看？** 填充约 200 笔逼真的演示交易：
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

成交会自动归组为交易（包括加仓与分批离场），重复记录总是被跳过 —— 这里不会出现重复计算。

## 3. 认识各个页面

| 页面 | 快捷键 | 用途 |
|------|--------|---------------|
| **仪表盘** | `G` `D` | 权益曲线、盈亏概览、连胜连亏、期望值、目标进度 |
| **交易** | `G` `T` | 交易记录 —— 筛选、排序，下钻查看成交与日志详情 |
| **日历** | `G` `C` | 按日 / 按周的盈亏热力图，支持下钻 |
| **报表** | `G` `S` | 胜率、盈利因子、期望值；按策略 / 小时 / 时段细分 |
| **笔记** | `G` `N` | 自由笔记与每日日志 |
| **策略手册** | `G` `P` | 你的策略库，每个策略关联使用它的交易 |
| **导入** | `G` `I` | 导入与导出 |
| **设置** | `⌘` `,` | 账户、风控规则、AI、API 令牌 |

`⌘K` 随时打开命令面板。

## 4. 养成复盘习惯

日志的价值在循环里，不在记录里：

1. **每笔交易都打上策略标签**（必要时加上错误类型与情绪）—— 没有标签的交易教不了你任何东西。
2. **每周看报表** —— 策略细分告诉你哪些模式真正赚钱；策略手册按期望值与盈利因子排序。
3. **设好护栏** —— **设置 → 规则**中的风控上限（单笔最大风险、单日最大亏损）会被新建交易的
   合规检查强制执行；年度目标则由仪表盘跟踪进度。
4. **稳定的仓位管理** —— 仓位计算器（`⌘⇧P`）基于你的账户权益与默认风险比例计算。
