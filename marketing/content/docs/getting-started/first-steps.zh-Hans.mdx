已经[跑起来了](/zh-Hans/docs/getting-started/quick-start)？下面是从空实例到一份真正有
洞察的交易日志的路径。

## 1. 初始化向导

首次访问时，TraderMemos 检测到空数据库会显示一次性初始化流程：

1. **Owner 账户** —— 登录名与密码（至少 10 位）。这是管理员账户；此后公开注册保持关闭，
   除非开启 `TM_ALLOW_REGISTRATION`。
2. **交易账户** —— 名称（默认 *Main*）、货币与初始资金。初始资金会成为现金流水中的一笔
   *期初余额* 存入记录。
3. **可选导入** —— 拖入 CSV 或 TraderMemos 的 JSON 备份为日志注入数据，也可以跳过从零开始。
   之后随时都能导入。

每个新用户会预置九个常见策略（回调、突破、反转……）—— 可在**策略手册**中重命名或替换。

## 2. 录入交易

三种方式，可自由组合：

- **连接券商** —— `/connect`（导入页面的 **Find my broker**，或账户页面的 **Connect broker**）
  打开可搜索的券商目录，
  按 **Auto-sync / File import / Manual** 分组。选中你的券商，就地选择或新建账户，然后按该
  券商的导出步骤操作；Interactive Brokers 则填入 Flex Query，首次同步会立即执行。
- **导入券商 CSV** —— 最快填满日志的方式。参见[导入交易](/zh-Hans/docs/guides/importing-trades)。
- **新建交易**（快捷键 `c` `t`）—— 手动录入，含成交行、策略、标签、情绪、截图与笔记。开启
  [AI 功能](/zh-Hans/docs/guides/ai-features)后，**扫描填充**可直接从券商截图提取成交。
- **自动化** —— IBKR 账户可通过 Flex Query 定时自动同步，在 `/connect` 或账户页面的
  **Interactive Brokers · Flex sync** 卡片中设置。
- **只是想先看看？** 填充约 200 笔逼真的演示交易：
  ```bash
  make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
  ```

成交会自动归组为交易（包括加仓与分批离场），重复记录总是被跳过 —— 这里不会出现重复计算。

## 3. 认识各个页面

| 页面 | 快捷键 | 用途 |
|------|--------|---------------|
| **首页** | `G` `H` | 权益曲线、盈亏概览、连胜连亏、期望值、目标进度 |
| **今日** | `G` `D` | 一页看完整个交易日 —— 例行清单、交易台（单日亏损护栏、持仓风险）、当日盈亏、错过的交易、每日日志 |
| **交易** | `G` `T` | 交易记录 —— 筛选、排序，下钻查看成交与日志详情 |
| **日历** | `G` `C` | 按日盈亏热力图，含每周合计与下钻 |
| **报表** | `G` `S` | 期望值、SQN、凯利比例、蒙特卡洛、执行质量；按策略 / 小时 / 时段细分 |
| **笔记** | `G` `N` | 自由笔记与每日日志 |
| **策略手册** | `G` `P` | 你的策略库，每个策略关联使用它的交易 |
| **计算器** | `G` `R` | R-multiple & FVG 交易规划器 |
| **导入** | `G` `I` | 导入与导出 |
| **设置** | `⌘` `,` | 个人档案（密码、双重认证）、一般（语言、时区、主题）、快捷键、账户、规则与警报、日志、AI、API 令牌、分享、用户、关于（版本、备份） |

`⌘K` 随时打开命令面板。没有快捷键的页面也在这里：**例行清单**与**错过的交易**（也可从今日页面
打开），以及**复盘**收件箱（`/review`）。其余工具 —— 仓位、凯利、货币换算、R-multiple & FVG、
高级图表、回放、财经日历、Year Wrapped —— 都在**工具**菜单里。所有快捷键均可在**设置 → 快捷键**中重新绑定。

## 4. 养成复盘习惯

日志的价值在循环里，不在记录里：

1. **每个交易日从今日页面开始**（`G` `D`）—— 勾选例行清单、留意单日亏损护栏、把放弃的机会记成
   错过的交易。参见[每日流程](/zh-Hans/docs/guides/daily-workflow)。
2. **清空复盘收件箱** —— 最近 14 天内已平仓但还没有执行评分的交易，会在**复盘**（`/review`，
   今日页面有入口）里逐笔排队。顺手打上策略、错误类型与情绪标签 —— 没有标签的交易教不了你任何东西。
3. **写周复盘** —— 每周六服务器会起草一篇附上本周数据的复盘笔记。你在 *Focus for next week*
   下写的要点，会成为今日页面与移动端首页上的**本周重点**；报表 → 行为会追踪你守住了多少。
   参见[周复盘](/zh-Hans/docs/guides/weekly-review)。
4. **让数据评判策略** —— 策略手册按判定（Edge、Promising、Watch、Too early、Execution leak、
   Bleeding）与期望值区间排序，四笔侥幸的盈利不会被当成优势。报表还提供错误成本（mistake tax）
   与 Edge Score —— 参见[分析](/zh-Hans/docs/guides/analytics)。
5. **设好护栏** —— **设置 → 规则**中的风控上限（单笔最大风险、单日最大亏损）会被新建交易的
   合规检查强制执行；年度目标由仪表盘跟踪进度；警报会及时提醒你
   （[警报与分享](/zh-Hans/docs/guides/alerts-and-sharing)）。仓位计算器（`⌘⇧P`）基于账户
   权益与默认风险比例计算。
