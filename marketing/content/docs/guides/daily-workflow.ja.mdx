**今日**（サイドバー、ホットキー `G` `D`）は取引日を 1 ページにまとめたものです。その日を始める
ルーティン、取引中のデスク、起きたこと、見送ったこと、そして 1 日を締めるログ。`/today` は常に
**マーケットタイムゾーン**での当日に解決されるので、アジアから見るニューヨークのセッションも
1 日として扱われます。

サイドバーは短く保たれています — **ホーム、今日、トレード、カレンダー、レポート**、続いて
**メモ、プレイブック、インポート**。ルーティンと見送ったトレードは今日ページのセクションで、
各カードからワンクリック、またはコマンドパレット（`⌘K` → *Routines* / *Missed trades*）で
全画面ページを開けます。

## 今日ページの構成

上から順に（カード名は Web UI の表記です）:

| カード | 内容 |
|------|-------|
| **This week's focus** | 直近の[週次レビュー](/ja/docs/guides/weekly-review)で決めた 1〜3 個のフォーカス |
| **Routine** | ステージ別の今日のチェックリスト。**Edit** でルーティン編集へ |
| **Daily loss limit** | 今日の最大日次損失のうち使った割合 — 70% から黄、到達で赤。設定 → ルール で **Max daily loss** を設定したときだけ表示 |
| **Open positions** | 現在のポジション（建てた日を問わず）、記録済みストップから算出した合計リスク、**ストップのない**ポジション数 |
| **Session summary** | 純損益、トレード数、勝率、手数料。ルール違反・行動のピル（過大リスク、リベンジ、サイズ過大…）、「N trades to review →」、その日のミス税 |
| **Intraday P&L** | 決済ごとに階段状に積み上がる実現損益 |
| **Trades** | その日のトレード — クリックで詳細ドロワー |
| **Missed trades** | その日に見て取らなかったセットアップ。**All** で一覧へ |
| **Daily log** | その日のメモと **New note** |

矢印で別の日（`/day/YYYY-MM-DD`）へ移動できます。デスク系カード（損失上限、オープンポジション）と
週次フォーカスは当日のみ表示されます。

## ルーティン

ルーティンはチェックリストを 3 つのステージ — **Before trading**（取引前）、**During trading**
（取引中）、**After trading**（取引後）— に分けたものです。編集画面は今日のルーティンカードの
**Edit**、`⌘K` → *Routines*、または 設定 → ルール → **Daily routine** → *Open Routines* から。

- **項目ごとの曜日。** 各項目は独自の曜日で動きます（*Every day*、*Weekdays*、任意の組み合わせ）。
  金曜だけの「週次準備」が月曜を崩しません。
- **履歴。** **Last 13 weeks** に日ごとのチェックが並び、**Completion**、**Streak**、ステージ別の
  達成率が出ます。過去の日をクリックすると、その日のチェックを確認・修正できます。
- **Streak** は全項目完了の連続日数です。リストのない日（平日ルーティンの週末）は数えず途切れず、
  未完了の今日も途切れません。
- **編集は履歴を書き換えません。** 項目の削除やステージ・曜日の変更は今日以降に適用され、過去の日は
  そのまま残ります。
- **チェックはマーケットの取引日に記録されます。** 現地の深夜 0 時を過ぎた取引後チェックも、
  そのセッションの日に入ります。

モバイルではホームに **今日のルーティン** カードがあり、**毎日のルーティン**（設定 →
トレードとジャーナル）で履歴を、**ルーティンを編集** でステージ別の編集画面を開けます。iOS では
**リマインダーに同期** を有効にすると、各項目がその曜日に繰り返すリマインダーとして
リマインダー App に入り（期限は指定した 1 つの時刻）、どちらで完了しても反対側にチェックが付きます。

## 見送ったトレード

見たけれど取らなかったセットアップを記録します: `⌘K` → *Missed trades*（`/missed`）、今日ページの
**Missed trades** カード、モバイルではツールメニューから。

| 項目 | 説明 |
|-------|-------|
| 銘柄、売買、見た日時 | 必須は銘柄と売買 |
| エントリー、損切り、目標価格 | 任意のプラン。売買方向と整合している必要があります。3 つ揃うと R で評価されます |
| 見送った理由 | ためらった、画面を離れていた、ルール外、その他 |
| 結果 | 未確認、利確に到達、損切りに到達、エントリーに届かず — 一覧からその場で変更可 |
| セットアップ、アカウント、メモ | 任意 |

評価: 利確到達はプランの R、損切り到達は −1R、未発動は 0R。サマリーには **取っていたら**（合計 R）、
**取り逃がした利益**（利確到達分）、**回避した損失**（損切り到達分）、結果未入力の件数が並び、
**理由別**・**セットアップ別** に内訳が出ます。見送ったトレードは**トレード統計に一切影響しません**。

## iOS のウィジェット・コントロール・Siri

iOS アプリには、アプリを開かずに使えるウィジェットと App Intents があります:

- **Daily Routine** ウィジェット — ホーム画面の小・中・大と、ロック画面（長方形・円形・インライン）。
  行をタップするとサーバーに直接チェック／解除します。サーバーに届かないときはキューに入り、
  ウィジェットは即座に再描画、次にアプリを開いたときに送信されます。30 分ごとと深夜 0 時に更新されます。
- **Missed Trades** ウィジェット — 小とロック画面: 取っていたら R、記録数、結果未入力の件数。
- **ショートカット / Siri** — *Check Off Routine Item*（Siri がどれかを尋ねます）、*Check Off Next
  Routine Item*、*Routine Progress*（読み上げ）、*Log Missed Trade*（銘柄と売買を尋ね、理由と
  プランは任意）。
- **コントロールセンター**（iOS 18） — *Next Routine Item* は次の未完了項目をチェック、*Log Missed
  Trade* はフォームを開きます。
