導入器會自動識別下列導出文件：拖入文件後，列映射、券商名稱和時區都會在預覽中自動填好。
未列出的平台仍可作為[通用成交 CSV](/zh-Hant/docs/guides/importing-trades) 導入 —— 自行映射列即可。

## 識別原理

- **CSV 預設**按文件表頭名稱匹配。識別出的導出文件會自動填好列映射和時間戳的解析時區，
  兩者在提交前都可修改。
- **MetaTrader 對賬單**按文件*內容*（而非文件名）識別 —— MT5 交易歷史報告和 MT4 對賬單是
  表格文檔而非 CSV，因此完全跳過映射步驟。

## 時區

券商導出的文件幾乎從不帶 UTC 偏移 —— 時間戳只是某個時區的牆鐘時間，而這個時區只有平台自己
知道。每個預設都帶有該平台慣例使用的時區：

- **美股券商**按美東時間導出。
- **期貨平台**按交易所（芝加哥）時間導出。
- **外匯/CFD 平台**（cTrader、DXtrade、Match-Trader）默認 **UTC**，但實際跟隨平台或門戶
  配置的偏移 —— 請檢查你的設置。
- **MetaTrader** 報告使用券商*服務器*的時鐘 —— 慣例是 EET/EEST（GMT+2/+3，讓日線隨紐約
  時段收盤），**絕不是 UTC**。

預覽會顯示假定的時區，並允許在提交前修改。自帶偏移的時間戳（帶 `Z` 或 `+hh:mm` 的
ISO 8601）會忽略該假定。如果導入後的交易時間偏差數小時，刪除該批次、重新導入，並在預覽中
改正時區。

## CSV 預設

| 平台 | 該導出的文件 | 時間解析為 | 數量單位 |
|----------|----------------|---------------|------------|
| **Interactive Brokers** | Flex 查詢或活動報表的成交 CSV（含 `Buy/Sell`、`TradePrice` 列） | 美東時間 | 股數 / 合約數 |
| **ThinkOrSwim** | Account Statement → *Account Trade History* 區塊導出 | 美東時間 | 股數 / 合約數 |
| **Webull** | 訂單導出（已成交訂單） | 美東時間 | 股數 |
| **Charles Schwab** | Transactions 導出 | 美東時間 | 股數 |
| **Tradovate** | Fills 導出 | 芝加哥（交易所時間） | 期貨合約數 |
| **NinjaTrader** | Executions 表格導出 | 美東時間 | 期貨合約數 |
| **cTrader** | *History* 標籤頁導出 —— 每筆已平倉位一行（開倉＋平倉） | UTC（平台配置的偏移） | 手數 |
| **DXtrade** | *Order History* 導出（自營交易門戶） —— 每筆成交一行 | UTC | 手數 |
| **Match-Trader** | 倉位導出（已平或持倉中） —— 每個倉位一行 | UTC | 手數 |

說明：

- **cTrader / Match-Trader** 的行是倉位級的：每行會生成一筆開倉*和*一筆平倉成交。
  Match-Trader 中仍持倉的行只導入開倉成交 —— 平倉後重新導入即可補全往返（重複會被跳過）。
- **DXtrade** 門戶因自營機構而異；預設匹配常見的 `Filled Volume` / `Fill Price`
  訂單歷史布局。

## MetaTrader 對賬單（MT4 / MT5）

無需 CSV —— 直接導出終端自帶的報告並原樣上傳：

| 終端 | 該導出的文件 | 導入內容 |
|----------|----------------|-----------------|
| **MetaTrader 5** | *交易歷史報告* —— 右鍵 History 標籤頁 → 報告 → **XLSX** 或 **HTML** | **Deals** 表：每筆 buy/sell 成交生成一條記錄 |
| **MetaTrader 4** | *對賬單*或詳細*賬戶歷史* —— 右鍵 Account History 標籤頁 → Save as Report（**HTML**） | **Closed Transactions** 表：每行生成開倉＋平倉一對成交 |

- 餘額行（入金、信用、更正）和已取消的掛單會被靜默跳過；字段損壞的行會以行錯誤形式顯示在
  預覽中，而不會中止導入。
- **佣金（commission）保持獨立成本項；庫存費/隔夜利息（swap，以及 fee 列）計入 fees** ——
  在 MetaTrader 賬戶中它們是兩種不同的成本。
- 時間默認按 MetaTrader **服務器時間慣例（EET/EEST）**解析。如果你的券商服務器使用 UTC 或
  當地時間，請在提交前於預覽中修改時區。

## 手數如何換算為數量

在按手計價的平台（cTrader、DXtrade、Match-Trader、MetaTrader）上，盈虧計算按品種解析
合約大小，而不是股票/期權乘數：

| 品種 | 每 1.00 手對應數量 |
|--------|--------------------|
| 外匯對（EURUSD、GBPJPY、…） | 100,000 |
| 黃金、鉑金、鈀金（XAU\*、XPT\*、XPD\*） | 100 |
| 白銀（XAG\*） | 5,000 |
| 指數 / 加密貨幣 CFD | 1（價格即合約價值） |

券商符號後綴（`EURUSD.r`、`XAUUSDm`）也能識別。

## 沒有你的券商？

只要成交導出包含品種 / 方向 / 數量 / 價格 / 時間列，就能通過
[通用 CSV 映射](/zh-Hant/docs/guides/importing-trades)導入 —— 預設只是省去映射步驟。
歡迎附上脫敏的樣例導出文件，在 [GitHub Issue](https://github.com/sinhong2011/TraderMemos/issues)
提出需求，我們會添加預設。
