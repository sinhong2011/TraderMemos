导入器会自动识别下列导出文件：拖入文件后，列映射、券商名称和时区都会在预览中自动填好。
未列出的平台仍可作为[通用成交 CSV](/zh-Hans/docs/guides/importing-trades) 导入 —— 自行映射列即可。

## 识别原理

- **CSV 预设**按文件表头名称匹配。识别出的导出文件会自动填好列映射和时间戳的解析时区，
  两者在提交前都可修改。
- **MetaTrader 对账单**按文件*内容*（而非文件名）识别 —— MT5 交易历史报告和 MT4 对账单是
  表格文档而非 CSV，因此完全跳过映射步骤。

## 时区

券商导出的文件几乎从不带 UTC 偏移 —— 时间戳只是某个时区的墙钟时间，而这个时区只有平台自己
知道。每个预设都带有该平台惯例使用的时区：

- **美股券商**按美东时间导出。
- **期货平台**按交易所（芝加哥）时间导出。
- **外汇/CFD 平台**（cTrader、DXtrade、Match-Trader）默认 **UTC**，但实际跟随平台或门户
  配置的偏移 —— 请检查你的设置。
- **MetaTrader** 报告使用券商*服务器*的时钟 —— 惯例是 EET/EEST（GMT+2/+3，让日线随纽约
  时段收盘），**绝不是 UTC**。

预览会显示假定的时区，并允许在提交前修改。自带偏移的时间戳（带 `Z` 或 `+hh:mm` 的
ISO 8601）会忽略该假定。如果导入后的交易时间偏差数小时，删除该批次、重新导入，并在预览中
改正时区。

## CSV 预设

| 平台 | 该导出的文件 | 时间解析为 | 数量单位 |
|----------|----------------|---------------|------------|
| **Interactive Brokers** | Flex 查询或活动报表的成交 CSV（含 `Buy/Sell`、`TradePrice` 列） | 美东时间 | 股数 / 合约数 |
| **ThinkOrSwim** | Account Statement → *Account Trade History* 区块导出 | 美东时间 | 股数 / 合约数 |
| **Webull** | 订单导出（已成交订单） | 美东时间 | 股数 |
| **Charles Schwab** | Transactions 导出 | 美东时间 | 股数 |
| **Tradovate** | Fills 导出 | 芝加哥（交易所时间） | 期货合约数 |
| **NinjaTrader** | Executions 表格导出 | 美东时间 | 期货合约数 |
| **cTrader** | *History* 标签页导出 —— 每笔已平仓位一行（开仓＋平仓） | UTC（平台配置的偏移） | 手数 |
| **DXtrade** | *Order History* 导出（自营交易门户） —— 每笔成交一行 | UTC | 手数 |
| **Match-Trader** | 仓位导出（已平或持仓中） —— 每个仓位一行 | UTC | 手数 |

说明：

- **cTrader / Match-Trader** 的行是仓位级的：每行会生成一笔开仓*和*一笔平仓成交。
  Match-Trader 中仍持仓的行只导入开仓成交 —— 平仓后重新导入即可补全往返（重复会被跳过）。
- **DXtrade** 门户因自营机构而异；预设匹配常见的 `Filled Volume` / `Fill Price`
  订单历史布局。

## MetaTrader 对账单（MT4 / MT5）

无需 CSV —— 直接导出终端自带的报告并原样上传：

| 终端 | 该导出的文件 | 导入内容 |
|----------|----------------|-----------------|
| **MetaTrader 5** | *交易历史报告* —— 右键 History 标签页 → 报告 → **XLSX** 或 **HTML** | **Deals** 表：每笔 buy/sell 成交生成一条记录 |
| **MetaTrader 4** | *对账单*或详细*账户历史* —— 右键 Account History 标签页 → Save as Report（**HTML**） | **Closed Transactions** 表：每行生成开仓＋平仓一对成交 |

- 余额行（入金、信用、更正）和已取消的挂单会被静默跳过；字段损坏的行会以行错误形式显示在
  预览中，而不会中止导入。
- **佣金（commission）保持独立成本项；库存费/隔夜利息（swap，以及 fee 列）计入 fees** ——
  在 MetaTrader 账户中它们是两种不同的成本。
- 时间默认按 MetaTrader **服务器时间惯例（EET/EEST）**解析。如果你的券商服务器使用 UTC 或
  当地时间，请在提交前于预览中修改时区。

## 手数如何换算为数量

在按手计价的平台（cTrader、DXtrade、Match-Trader、MetaTrader）上，盈亏计算按品种解析
合约大小，而不是股票/期权乘数：

| 品种 | 每 1.00 手对应数量 |
|--------|--------------------|
| 外汇对（EURUSD、GBPJPY、…） | 100,000 |
| 黄金、铂金、钯金（XAU\*、XPT\*、XPD\*） | 100 |
| 白银（XAG\*） | 5,000 |
| 指数 / 加密货币 CFD | 1（价格即合约价值） |

券商符号后缀（`EURUSD.r`、`XAUUSDm`）也能识别。

## 没有你的券商？

只要成交导出包含品种 / 方向 / 数量 / 价格 / 时间列，就能通过
[通用 CSV 映射](/zh-Hans/docs/guides/importing-trades)导入 —— 预设只是省去映射步骤。
欢迎附上脱敏的样例导出文件，在 [GitHub Issue](https://github.com/sinhong2011/TraderMemos/issues)
提出需求，我们会添加预设。
