兩項 AI 功能都**默認關閉**、完全可選 —— 不開啓它們 TraderMemos 也能完整使用。它們對接任何
**OpenAI 兼容**的 `chat/completions` 端點：OpenAI、OpenRouter、Azure OpenAI，或
Ollama / LM Studio 等本地服務。密鑰由你自己提供。

兩者都在**設置 → AI** 中配置。先了解兩點：

- 設置是**全服務器級**的（每個實例一份配置，而非按用戶區分）。
- API 密鑰只保存在服務端 —— 保存後瀏覽器只能看到打碼的提示。

## 截圖掃描（成交提取）

從券商 App 截圖中提取成交信息，免去手動輸入。在**新建交易**抽屜中，**掃描填入**接受一張或
多張 PNG / JPEG / WebP 截圖，或 CSV / JSON 成交文件，並先在審閱浮層中暫存，不會直接改動表單：

- 每個文件單獨一行，顯示模型讀取時的進度；
- 全部完成後，按代碼分卡片顯示成交、平均進場 / 出場價與 FIFO 淨盈虧（多代碼截圖也支持）；
- 只有點擊**填入表單**時表單才會改變。若甚麼都沒讀到，則顯示**關閉**，並保留模型的說明作為原因。

細節由伺服器處理：成交時間按截圖上顯示的時區讀取（如時間旁的 `美東` 標籤），否則使用你的市場
時區；缺失的年份會補全且不會讓成交落在未來。已撤單、被拒與未成交的訂單會被跳過，多 / 空方向
由成交本身判斷。服務商過載時伺服器會重試兩次，仍失敗則返回 **503 `ocr_busy`** 並提示稍後重試。

在**設置 → AI → 截圖掃描**中配置：

| 字段 | 說明 |
|-------|-------|
| 啓用 | 打開該功能 |
| API 基址 | 如 `https://api.openai.com/v1`、`https://openrouter.ai/api/v1`、`http://localhost:11434/v1` |
| 模型 | 必須支持**視覺** —— 默認 `gpt-4o-mini`。**獲取模型列表**可列出端點提供的模型 |
| API 密鑰 | 後續編輯時留空表示保留當前密鑰 |
| 自定義提示詞 | 可選 —— 留空使用內置的成交提取提示詞 |

保存前先用**測試**驗證連通性。圖片上限 10 MiB（`TM_OCR_MAX_BYTES`），請求 90 秒超時
（`TM_OCR_VISION_TIMEOUT_SEC`）—— 較慢的本地模型可能需要更長的超時，同時你的
[反向代理](/zh-Hant/docs/self-hosting/reverse-proxy)須允許 ≥ 120 秒。

## 交易教練

在任意交易的詳情頁點擊 **Ask AI**，會把交易信息 —— 成交、盈虧、R 倍數、MAE/MFE、策略、情緒、
標籤、你的筆記 —— 連同你**進場時的狀態**（當日與當週此前的盈虧、連勝連虧、回撤、最近幾筆平倉的
情緒）一起發送給模型。返回的覆盤包括：

- **覆盤建議** —— 模型邊寫邊逐條串流顯示；
- 一條**下一步行動** —— 下一筆交易可檢查的具體指令；
- 單筆**執行評分** —— 進場、出場、風險、節奏，與報表同一 0–100 刻度。

覆盤會被保存：再次打開該交易會顯示上一次的覆盤，按鈕變為 **Regenerate**（重新生成）。教練關閉
或不可用時，面板回退到內置的規則化提示。

在**設置 → AI → 交易教練**中配置：字段與上文相同（任何對話模型均可 —— 不需要視覺能力），
另有可選的**系統提示詞**用於調整教練風格。

在行動端，模型一欄會打開可搜尋、按廠商分組的選擇面板。截圖掃描會把不能識圖的模型隱藏在
*Show all models* 之後；端點未列出的模型 id 也可以直接輸入。

## 通過環境變量預設默認值

腳本化部署可用 `TM_OCR_*` / `TM_COACH_*` 變量預先配置兩項功能 —— 參見
[配置參考](/zh-Hant/docs/self-hosting/configuration)。環境變量只是默認值：一旦在 UI 中
保存過設置，數據庫中的值優先。

## 隱私

交易數據與截圖**只會**發送到你配置的端點。指向本地模型的話，任何數據都不會離開你的機器。
