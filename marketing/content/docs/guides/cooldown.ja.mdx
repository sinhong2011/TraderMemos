title: クールダウン
description: リベンジトレードを断ち切るサーキットブレーカー — 復帰ゲート付きの時限休止。手動でも、自分のリスクルールからでも開始できます。
---

クールダウンモードは**既定でオフ**です。**設定 → ルール**（モバイルは**設定 → 取引と
ジャーナル → リスクルール**）でオンにすると現れます。オフのままなら、どこにも表示
されません。

クールダウンは、次のトレードの前に置く時限休止です。実行中は**取引入力がロック**
されます — Web はトレードログにベールを掛けて「新規トレード」をクールダウンパネルへ
誘導し、モバイルは取引フォームをロックします。ジャーナルを読むことは自由です。
ロックされるのは「行動」であって「閲覧」ではありません。

クールダウンを終えるには、待つだけでは足りません。**復帰ゲート**が 3 つの質問をします —
何に引き寄せられていたか（リベンジ、FOMO、退屈、恐怖、自己証明）、復帰後に許す
プレイブックのセットアップ 1 つ、そして今日の残りのルール（*半分のサイズ*、
*1 トレードのみ*、*今日はここまで*）。タイマー終了**前**の解除も可能ですが、
40 文字以上の振り返りを書いた場合だけです。タイピングそのものが摩擦です。

## 開始方法

- **Web** — トレード画面ツールバーの **Cooldown** ボタン（または
  `/trades?panel=cooldown`）。タブタイトルがカウントを続けます（`⏸ 12:34`）。
- **モバイル** — ホームのツールメニューの「クールダウン」、またはロック中の
  トレード **+**。
- **自動** — **設定 → ルール**の**自動クールダウン**を設定すると、日次損失・連敗・
  1 日の取引数上限のルールに抵触した時点でサーバー自身がクールダウンを開始し、
  登録済みの各デバイスに通知します。ジャーナルはあなたが 3 連敗したことを知って
  います — 頼まれるのを待ちません。

## 約束には結果が伴う

復帰時に選んだルールは後から採点されます:

- **ルール遵守**（レポート → リスク）は、復帰ルールを決めた日にそのルールに反して
  取ったトレードを数えます。
- **クールダウン**（レポート → 行動）は、解除後 1 時間以内のトレードと、クールダウン
  しなかった日の連敗後 1 時間以内のトレードを比較します — 休止が機能しているかを
  示す唯一の数字です。

## iOS では

**Live Activity** がロック画面と Dynamic Island にカウントダウンを表示するので、アプリ
を開かなくても残り時間が分かります。タイマー終了後は自動で「復帰ゲートに回答」へ
切り替わります。
