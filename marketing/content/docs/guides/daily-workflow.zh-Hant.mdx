**今日**（側邊欄，快捷鍵 `G` `D`）把交易日放在一頁裡：開啟一天的例行清單、盤中的交易台、
發生了甚麼、放過了甚麼，以及收尾的日誌。`/today` 始終解析為**市場時區**下的當天，所以在亞洲
查看紐約盤時，一個交易時段仍是同一天。

側邊欄保持精簡 —— **首頁、今日、交易、日曆、報表**，然後是**筆記、策略庫、匯入**。例行清單和
錯過的交易是今日頁面的板塊，從各自卡片一鍵打開，或用命令面板（`⌘K` → *Routines* /
*Missed trades*）打開完整頁面。

## 今日頁面包含甚麼

從上到下（卡片名為 Web 介面中的原文）：

| 卡片 | 顯示 |
|------|-------|
| **This week's focus** | 上一次[每週回顧](/zh-Hant/docs/guides/weekly-review)定下的 1–3 條重點 |
| **Routine** | 按階段分組的今日清單；**Edit** 打開編輯器 |
| **Daily loss limit** | 今天的最大單日虧損額度已用多少 —— 70% 起變黃，觸及變紅。只有在 設定 → 規則 中設定了 **Max daily loss** 才顯示 |
| **Open positions** | 目前所有持倉（不論何時開倉）、按已記錄止損算出的總持倉風險，以及**沒有止損**的持倉數 |
| **Session summary** | 淨盈虧、交易數、勝率、手續費；違規與行為標籤（超額風險、報復交易、倉位過大…）；"N trades to review →"；當天的錯誤稅 |
| **Intraday P&L** | 每筆平倉階梯式累計的已實現盈虧 |
| **Trades** | 當天的交易 —— 點擊打開詳情抽屜 |
| **Missed trades** | 當天看到但沒做的形態；**All** 打開完整記錄 |
| **Daily log** | 當天的筆記，以及 **New note** |

箭頭可切換到其他日期（`/day/YYYY-MM-DD`）；交易台卡片（虧損上限、持倉）和每週重點只在當天顯示。

## 例行清單

例行清單把你的檢查項分為三個階段 —— **Before trading**（交易前）、**During trading**（交易中）、
**After trading**（交易後）。編輯器可從今日例行卡片的 **Edit**、`⌘K` → *Routines*，或
設定 → 規則 → **Daily routine** → *Open Routines* 打開。

- **按項目設定星期。** 每個項目有自己的星期（*Every day*、*Weekdays* 或任意組合），只在週五做的
  「週度準備」不會打斷週一。
- **歷史。** **Last 13 weeks** 顯示每天的勾選，附 **Completion**（完成率）、**Streak**（連續天數）
  和各階段完成率。點擊過去的某天可查看或修正當天的勾選。
- **Streak** 統計連續全部完成的天數。沒有清單的日子（工作日清單的週末）既不計入也不中斷，未完成的
  今天也不會中斷。
- **編輯不會改寫歷史。** 刪除項目或修改其階段、星期，從今天起生效 —— 過去的日子保持原樣。
- **勾選記在市場交易日上。** 本地午夜之後的盤後勾選，仍算在它結束的那個交易時段。

流動端首頁有**今日例行**卡片；**每日例行**（設定 → 交易與日誌）顯示歷史，**編輯例行清單**是按階段
分組的編輯器。iOS 上開啟**同步至提醒事項**後，每個項目會成為提醒事項 App 中按其星期重複的提醒
（到期時間為你選定的一個時刻）—— 在任一邊完成，另一邊都會打勾。

## 錯過的交易

記錄看到但沒做的形態：`⌘K` → *Missed trades*（`/missed`）、今日頁面的 **Missed trades** 卡片，
或流動端的工具選單。

| 欄位 | 說明 |
|-------|-------|
| 代號、方向、看到的時間 | 必填：代號和方向 |
| 入場、止損價、目標價 | 可選計劃；必須與方向一致。三者齊全時按 R 計價 |
| 沒有做的原因 | 猶豫了、不在螢幕前、不符合我的規則、其他 |
| 結果如何 | 尚未查看、觸及目標、觸及止損、未觸發 —— 可在列表中直接修改 |
| 策略、帳戶、筆記 | 可選 |

計分：觸及目標按計劃 R 計，觸及止損記 −1R，未觸發記 0R。匯總顯示**如果做了**（淨 R）、
**錯失的利潤**（目標命中）、**避開的虧損**（止損命中）以及仍待填寫結果的數量，並按**原因**和
**策略**細分。錯過的交易**從不影響你的交易統計**。

## iOS 小工具、控制與 Siri

iOS App 提供無需打開 App 即可使用的小工具和 App Intents：

- **Daily Routine** 小工具 —— 主畫面小、中、大尺寸，以及鎖定畫面（矩形、圓形、內嵌）。點一行即可
  直接在伺服器上勾選或取消。伺服器無法連線時勾選會排隊，小工具立即重繪，下次打開 App 時發送。
  每 30 分鐘和午夜更新。
- **Missed Trades** 小工具 —— 小尺寸和鎖定畫面：如果做了的 R、記錄數、待填結果數。
- **捷徑 / Siri** —— *Check Off Routine Item*（Siri 會問是哪一項）、*Check Off Next Routine
  Item*、*Routine Progress*（語音播報）、*Log Missed Trade*（詢問代號和方向；原因和計劃可選）。
- **控制中心**（iOS 18）—— *Next Routine Item* 勾選下一個未完成項；*Log Missed Trade* 打開表單。
