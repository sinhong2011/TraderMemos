**今日**（侧边栏，快捷键 `G` `D`）把交易日放在一页里：开启一天的例行清单、盘中的交易台、
发生了什么、放过了什么，以及收尾的日志。`/today` 始终解析为**市场时区**下的当天，所以在亚洲
查看纽约盘时，一个交易时段仍是同一天。

侧边栏保持精简 —— **首页、今日、交易、日历、报表**，然后是**笔记、策略库、导入**。例行清单和
错过的交易是今日页面的板块，从各自卡片一键打开，或用命令面板（`⌘K` → *Routines* /
*Missed trades*）打开完整页面。

## 今日页面包含什么

从上到下（卡片名为 Web 界面中的原文）：

| 卡片 | 显示 |
|------|-------|
| **This week's focus** | 上一次[每周回顾](/zh-Hans/docs/guides/weekly-review)定下的 1–3 条重点 |
| **Routine** | 按阶段分组的今日清单；**Edit** 打开编辑器 |
| **Daily loss limit** | 今天的最大单日亏损额度已用多少 —— 70% 起变黄，触及变红。只有在 设置 → 规则 中设置了 **Max daily loss** 才显示 |
| **Open positions** | 当前所有持仓（不论何时开仓）、按已记录止损算出的总持仓风险，以及**没有止损**的持仓数 |
| **Session summary** | 净盈亏、交易数、胜率、手续费；违规与行为标签（超额风险、报复交易、仓位过大…）；"N trades to review →"；当天的错误税 |
| **Intraday P&L** | 每笔平仓阶梯式累计的已实现盈亏 |
| **Trades** | 当天的交易 —— 点击打开详情抽屉 |
| **Missed trades** | 当天看到但没做的形态；**All** 打开完整记录 |
| **Daily log** | 当天的笔记，以及 **New note** |

箭头可切换到其他日期（`/day/YYYY-MM-DD`）；交易台卡片（亏损上限、持仓）和每周重点只在当天显示。

## 例行清单

例行清单把你的检查项分为三个阶段 —— **Before trading**（交易前）、**During trading**（交易中）、
**After trading**（交易后）。编辑器可从今日例行卡片的 **Edit**、`⌘K` → *Routines*，或
设置 → 规则 → **Daily routine** → *Open Routines* 打开。

- **按项目设置星期。** 每个项目有自己的星期（*Every day*、*Weekdays* 或任意组合），只在周五做的
  "周度准备"不会打断周一。
- **历史。** **Last 13 weeks** 显示每天的勾选，附 **Completion**（完成率）、**Streak**（连续天数）
  和各阶段完成率。点击过去的某天可查看或修正当天的勾选。
- **Streak** 统计连续全部完成的天数。没有清单的日子（工作日清单的周末）既不计入也不中断，未完成的
  今天也不会中断。
- **编辑不会改写历史。** 删除项目或修改其阶段、星期，从今天起生效 —— 过去的日子保持原样。
- **勾选记在市场交易日上。** 本地午夜之后的盘后勾选，仍算在它结束的那个交易时段。

移动端首页有**今日例行**卡片；**每日例行**（设置 → 交易与日志）显示历史，**编辑例行清单**是按阶段
分组的编辑器。iOS 上开启**同步至提醒事项**后，每个项目会成为提醒事项 App 中按其星期重复的提醒
（到期时间为你选定的一个时刻）—— 在任一边完成，另一边都会打勾。

## 错过的交易

记录看到但没做的形态：`⌘K` → *Missed trades*（`/missed`）、今日页面的 **Missed trades** 卡片，
或移动端的工具菜单。

| 字段 | 说明 |
|-------|-------|
| 代号、方向、看到的时间 | 必填：代号和方向 |
| 入场、止损价、目标价 | 可选计划；必须与方向一致。三者齐全时按 R 计价 |
| 没有做的原因 | 犹豫了、不在屏幕前、不符合我的规则、其他 |
| 结果如何 | 尚未查看、触及目标、触及止损、未触发 —— 可在列表中直接修改 |
| 策略、账户、笔记 | 可选 |

计分：触及目标按计划 R 计，触及止损记 −1R，未触发记 0R。汇总显示**如果做了**（净 R）、
**错失的利润**（目标命中）、**避开的亏损**（止损命中）以及仍待填写结果的数量，并按**原因**和
**策略**细分。错过的交易**从不影响你的交易统计**。

## iOS 小组件、控制与 Siri

iOS App 提供无需打开 App 即可使用的小组件和 App Intents：

- **Daily Routine** 小组件 —— 主屏幕小、中、大尺寸，以及锁定屏幕（矩形、圆形、内联）。点一行即可
  直接在服务器上勾选或取消。服务器不可达时勾选会排队，小组件立即重绘，下次打开 App 时发送。
  每 30 分钟和午夜刷新。
- **Missed Trades** 小组件 —— 小尺寸和锁定屏幕：如果做了的 R、记录数、待填结果数。
- **快捷指令 / Siri** —— *Check Off Routine Item*（Siri 会问是哪一项）、*Check Off Next Routine
  Item*、*Routine Progress*（语音播报）、*Log Missed Trade*（询问代号和方向；原因和计划可选）。
- **控制中心**（iOS 18）—— *Next Routine Item* 勾选下一个未完成项；*Log Missed Trade* 打开表单。
