TraderMemos 提供一個 [Model Context Protocol](https://modelcontextprotocol.io) 端點。AI 助手可以查詢交易、
運行績效報告、閱讀筆記，並且僅在你允許時記錄成交、編輯日誌。

這不是內置的 [AI 教練](/docs/guides/ai-features)，也不配置任何 LLM 提供商。助手運行在它自己的環境
（xAI、Anthropic、你的電腦），用你提供的令牌調用你的 TraderMemos 服務器。

## 開啓

1. **設置 → API → 訪問令牌 → 生成令牌。** 每個助手各建一個（`Grok`、`Claude Code` 等），以便單獨撤銷。
   複製 `tm_pat_…` 密鑰 —— 它只顯示一次。
2. **設置 → API → AI 助理的 MCP → 允許 MCP 連線。** 開啓之前，MCP 端點會以 `403 mcp_disabled`
   拒絕所有令牌。
3. 想要只讀助手就保持 **允許修改** 關閉；需要寫入時再開啓。

同一區域會顯示端點 URL 以及各客戶端可直接粘貼的配置。

## 連接信息

| | |
|---|---|
| 端點 | `https://<your-host>/api/v1/mcp`（API 獨立部署時爲 API 主機） |
| 傳輸 | Streamable HTTP，無狀態，JSON 響應 |
| 認證 | `Authorization: Bearer tm_pat_…` —— 僅限個人訪問令牌 |
| 權限 | 除非開啓 **允許修改**，否則只讀 |

Web 應用的登錄會話（JWT）會被刻意拒絕：個人訪問令牌有名稱、可列出、能看到最近使用來源，並可逐個撤銷。

## 權限

| 工具 | 權限 | 作用 |
|------|------|------|
| `get_connection_info` | 讀 | 報告只讀或讀寫，以及服務器版本 |
| `list_accounts` | 讀 | 賬戶及其 ID |
| `list_trades` | 讀 | 交易（最新在前），可按賬戶、日期、代碼、狀態、方向、持倉時長篩選並分頁 |
| `get_trade` | 讀 | 單筆交易，含成交、日誌、標籤與 MAE/MFE |
| `get_analytics` | 讀 | `summary`, `r_summary`, `daily`, `equity_curve`, `breakdown`, `behavior`, `compliance`, `execution_score`, `edge_score`, `setup_scorecard`, `mistake_tax` |
| `list_notes` / `get_note` | 讀 | 日誌筆記、每日記錄、周複盤 |
| `list_tags` / `list_setups` | 讀 | 記錄日誌所需的 ID |
| `log_execution` | 寫 | 記錄一筆成交，服務器會把成交歸併爲交易；重複提交同一成交不會重複記錄 |
| `update_trade_journal` | 寫 | 筆記、策略、標籤、風險、止損/目標、情緒、評分 |
| `delete_trade` | 寫 | 刪除交易及其成交與附件 |
| `create_note` / `update_note` / `delete_note` | 寫 | 日誌筆記 |

**允許修改** 關閉時，寫入工具**不會出現在列表中**，即使被調用也會被服務器拒絕。開關變更從下一個請求起生效；
緩存了工具列表的客戶端可能需要刷新才能顯示新開放的工具。

每個工具都會以助手的令牌調用對應的 [REST 端點](/docs/api-reference)，因此它能看到的與該令牌通過 API
能看到的完全一致：只有你的數據。

<Callout type="warn">
工具帶有 MCP 註解（`readOnlyHint`、`destructiveHint` 等），供客戶端標記和確認高風險調用。它們只是給客戶端
界面的提示，不是安全機制。助手能做什麼由服務器決定：令牌與 **允許修改** 開關。刪除無法撤銷 —— 除非你希望
助手編輯日誌，否則請保持寫入關閉。
</Callout>

只有已登錄的會話才能更改 MCP 開關。使用令牌（包括交給助手的那個）會得到 `403 session_required`，
因此助手無法自行獲得寫入權限。

## 連接客戶端

### Grok（xAI API）

xAI 的 [遠程 MCP 工具](https://docs.x.ai/developers/tools/remote-mcp) 通過 Streamable HTTP 連接，並在
`Authorization` 頭中發送令牌。調用來自 xAI 的服務器，所以你的端點必須**能從互聯網通過 HTTPS 訪問** ——
`localhost` 實例無法使用。

```python
from xai_sdk import Client
from xai_sdk.tools import mcp

client = Client()  # reads XAI_API_KEY
chat = client.chat.create(
    model="grok-4.7",
    tools=[mcp(
        server_url="https://journal.example.com/api/v1/mcp",
        server_label="tradermemos",
        authorization="tm_pat_…",
    )],
)
```

在 `authorization` 中直接填入令牌即可；TraderMemos 接受帶或不帶 `Bearer ` 前綴的寫法。相同字段
（`server_url`、`server_label`、`authorization`）也適用於 `https://api.x.ai/v1/responses` 的 OpenAI 兼容
Responses API。用 `allowed_tool_names` 可以只開放部分工具。

### Grok Build

[Grok Build](https://docs.x.ai/build/features/mcp-servers) 運行在你的電腦上，因此局域網或 `localhost` 地址也可以：

```bash
grok mcp add --transport http tradermemos https://journal.example.com/api/v1/mcp \
  --header "Authorization: Bearer ${TRADERMEMOS_TOKEN}"
```

<Callout>
**grok.com 和 Grok 應用**的自定義連接器通過 URL 添加並使用 OAuth 登錄。TraderMemos 只支持個人訪問令牌認證，
不提供 OAuth 服務器，請改用 xAI API 或 Grok Build。
</Callout>

### Claude Code

```bash
claude mcp add --transport http tradermemos https://journal.example.com/api/v1/mcp \
  --header "Authorization: Bearer ${TRADERMEMOS_TOKEN}"
```

### 其他客戶端

Cursor、VS Code、Windsurf 等大多數 MCP 客戶端都接受 Streamable HTTP URL 加請求頭：

```json
{
  "mcpServers": {
    "tradermemos": {
      "type": "http",
      "url": "https://journal.example.com/api/v1/mcp",
      "headers": { "Authorization": "Bearer tm_pat_…" }
    }
  }
}
```

只支持以 OAuth 連接遠程服務器的客戶端（例如 claude.ai 自定義連接器）暫時無法連接，原因與 grok.com 相同。

## 斷開助手

- **單個助手：** 在 **設置 → API → 訪問令牌** 撤銷它的令牌。每次工具調用都會重新校驗令牌，因此從下一個請求起即被拒絕。
- **所有助手：** 關閉 **允許 MCP 連線**。
- **誰連接過？** 每個令牌都有客戶端 IP 與 User-Agent 的活動記錄（[詳情](/docs/guides/api-tokens#where-has-a-token-been-used)）。

令牌創建後不會出現在 TraderMemos 的日誌或設置頁面中。不要把令牌粘貼到與助手的對話裏 —— 放進客戶端配置或環境變量。

## 自託管說明

- `TM_MCP_ENABLED=false` 會把端點從服務器中完全移除（[配置](/docs/self-hosting/configuration)）。默認開啓，
  但在用戶自行啓用前不起作用。
- 端點位於 `/api/v1` 下，已轉發 API 的反向代理無需改動。它是無狀態的：不需要粘性會話，重啓和多副本都沒問題。
- 排查問題可以用 `curl`：

```bash
curl -s https://journal.example.com/api/v1/mcp \
  -H "Authorization: Bearer $TRADERMEMOS_TOKEN" \
  -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

`401` 表示令牌缺失、錯誤、過期或已撤銷；`403 mcp_disabled` 表示該賬戶未開啓 MCP；`404` 表示服務器以
`TM_MCP_ENABLED=false` 運行。
