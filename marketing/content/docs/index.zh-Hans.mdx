## 什么是 TraderMemos？

TraderMemos 是一款**自托管交易日志**，面向希望将自己的交易表现数据保留在自有基础设施上的交易者
—— 提供仪表盘、盈亏日历、交易记录、策略手册与报表。无需订阅，不被供应商锁定。

TradeZella、TraderSync 等云端交易日志固然精致，但你的交易优势藏在数据里。TraderMemos 延续了
[Ghost](https://github.com/TryGhost/Ghost)、[Umami](https://github.com/umami-software/umami) 与
[Plane](https://github.com/makeplane/plane) 的自托管理念：运行在你自己的基础设施上，掌控数据库，
无需许可即可自由扩展。

## 功能

- **仪表盘** —— 权益曲线、期望值、连胜连亏、持仓时长与年度目标进度，可按单账户或跨账户组合查看
- **交易记录** —— 成交明细自动归组为交易，可筛选、排序、打标签，并下钻查看含 MAE/MFE 图表的执行细节
- **盈亏日历** —— 按日热力图，含每周合计与单日明细下钻
- **报表** —— 期望值、SQN、凯利比例、MAE/MFE、蒙特卡洛与执行质量，按策略 / 小时 / 时段细分，并可保存为常用视图
- **策略手册** —— 策略库与使用该策略的交易记录相互关联，附规则遵守评分
- **导入** —— 券商 CSV 预设、MT4/MT5 对账单、IBKR Flex 同步与 tm-sync 对账单监控 —— 参见[支持的券商](/zh-Hans/docs/guides/supported-brokers)
- **警报** —— 风控规则、每日亏损上限与 Prop 回撤预警，通过推送与 Webhook 发送
- **K 线回放** —— 对任意品种逐根 K 线回测，成绩记入可持久保存的模拟账户
- **分享** —— 可随时撤销的只读业绩链接与分享卡片
- **工具** —— 仓位 / 汇率 / 凯利计算器、高级图表、财经日历与现金流水账
- **AI**（可选）—— 截图自动提取成交信息 + AI 交易教练，基于兼容 OpenAI 的 API，使用你自己的密钥
- **API 访问** —— 个人访问令牌（`tm_pat_…`）可用于 MCP / 脚本；OpenAPI 文档位于 `/docs`
- **移动应用**（测试版）—— iOS 与 Android 原生随身版，支持离线记录；小组件、实时活动与 Siri 快速记账为 iOS 专属 —— 参见[移动应用](/zh-Hans/docs/getting-started/mobile-app)

## 技术栈

| 层级 | 技术栈 |
|-------|-------|
| **API** | Go · Echo · sqlc · golang-migrate · SQLite / Postgres |
| **Web** | React · Vite+ · TanStack Router/Query/Form · Tailwind |
| **移动端** | Expo（iOS / Android）· PanelUI + Uniwind |
| **设计** | shadcn/ui + coss ui 设计令牌 |
