## 什麼是 TraderMemos？

TraderMemos 是一款**自託管交易日誌**，面向希望將自己的交易表現數據保留在自有基礎設施上的交易者
—— 提供儀表盤、盈虧日曆、交易記錄、策略手冊與報表。無需訂閱，不被供應商鎖定。

TradeZella、TraderSync 等雲端交易日誌固然精緻，但你的交易優勢藏在數據裏。TraderMemos 延續了
[Ghost](https://github.com/TryGhost/Ghost)、[Umami](https://github.com/umami-software/umami) 與
[Plane](https://github.com/makeplane/plane) 的自託管理念：運行在你自己的基礎設施上，掌控數據庫，
無需許可即可自由擴展。

## 功能

- **儀表盤** —— 權益曲線、期望值、連勝連虧、持倉時長與年度目標進度，可按單賬戶或跨賬戶組合查看
- **交易記錄** —— 成交明細自動歸組爲交易，可篩選、排序、打標籤，並下鑽查看含 MAE/MFE 圖表的執行細節
- **盈虧日曆** —— 按日熱力圖，含每週合計與單日明細下鑽
- **報表** —— 期望值、SQN、凱利比例、MAE/MFE、蒙地卡羅與執行品質，按策略 / 小時 / 時段細分，並可保存爲常用視圖
- **策略手冊** —— 策略庫與使用該策略的交易記錄相互關聯，附規則遵守評分
- **導入** —— 券商 CSV 預設、MT4/MT5 對賬單、IBKR Flex 同步與 tm-sync 對賬單監控 —— 參見[支持的券商](/zh-Hant/docs/guides/supported-brokers)
- **警報** —— 風控規則、每日虧損上限與 Prop 回撤預警，通過推送與 Webhook 發送
- **K 線回放** —— 對任意品種逐根 K 線回測，成績記入可持久保存的模擬賬戶
- **分享** —— 可隨時撤銷的只讀業績鏈接與分享卡片
- **工具** —— 倉位 / 匯率 / 凱利計算器、高級圖表、財經日曆與現金流水賬
- **AI**（可選）—— 截圖自動提取成交信息 + AI 交易教練，基於兼容 OpenAI 的 API，使用你自己的密鑰
- **API 訪問** —— 個人訪問令牌（`tm_pat_…`）可用於 MCP / 腳本；OpenAPI 文檔位於 `/docs`
- **行動應用**（測試版）—— iOS 與 Android 原生隨身版，支援離線記錄；小工具、即時動態與 Siri 快速記帳為 iOS 專屬 —— 參見[行動應用](/zh-Hant/docs/getting-started/mobile-app)

| 層級 | 技術棧 |

| **API** | Go · Echo · sqlc · golang-migrate · SQLite / Postgres |
| **Web** | React · Vite+ · TanStack Router/Query/Form · Tailwind |
| **移動端** | Expo（iOS / Android）· PanelUI + Uniwind |
| **設計** | shadcn/ui + coss ui 設計令牌 |
